Selected work

CyberDNA — Insider Threat Detection System

CASE-01 / thesis

Graduation thesis project modeling insider threats through behavioral fingerprinting. My sections cover the technical architecture and cybersecurity components: an event pipeline that encodes user activity into sequences, an autoencoder-based detection engine, and a risk-scoring layer that feeds an explainable, real-time dashboard — trained against the CERT insider-threat dataset.

BioVault — Biometric-First Privileged Access

CASE-02 / design

A privileged access management concept where employees authenticate with biometrics but never see the underlying credentials — the vault handles checkout, session monitoring, and audit logging on their behalf. Grounded in NIST SP 800-63 and WebAuthn/FIDO2, and shaped directly by analyzing the Verkada breach rather than working from theory.

PAM designWebAuthn / FIDO2NIST SP 800-63

SQL Injection & SSH Hardening Labs

CASE-03 / lab

Exploited UNION-based SQL injection and enumerated an Oracle database on Web Security Academy targets using Burp Suite and SQLmap. Separately, ran an SSH brute-force attack with Metasploit's ssh_login module against an Ubuntu server, then hardened it with Fail2ban and sshd_config changes — full recon-to-remediation loop, documented end to end.
